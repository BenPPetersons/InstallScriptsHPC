# Installation Script
These are simple scripts for installing dependencies for Ansys Fluent software. This is primarily for platforms using either Debian based or RHEL based distributions, utilizing Ansys 2023 R1 and later. In addition, a script which adds environment variables needed for Ansys Fluent are also included in this repository.
